## Estructura del proyecto
> **Showcase_U**: carpeta con el contenido de todos los archivos del proyecto.
### Estructura interna
- **`showcase_u_create_database.sql`**: código SQL empleado en la creación de la base de datos y sus tablas.
- **`index.php`**: archivo principal de inicio del proyecto.
- **Carpetas**:
  - **`assets/`**: contiene los recursos utilizados en la web.
    - **`css/`**: contiene los archivos de estilos aplicados al proyecto.
    - **`img/`**: contiene las imágenes utilizadas en la web.
  - **`config/`**: contiene los archivos de configuración del proyecto.
    - **`db.php`**: archivo de conexión a la base de datos.
  - **`public/`**: contiene los archivos públicos de la aplicación.
    - **`index.php`**: página principal visible desde el navegador.
    - **`insertar.php`**: archivo encargado de insertar datos en la base de datos.
